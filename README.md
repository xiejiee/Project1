# Project1 洗袜机

这个工程先在电脑上验证洗袜流程。需要 Node.js 18 或更新版本，无需安装第三方依赖。

```powershell
node sim/demo.mjs
node --test test/washer.test.mjs
```

模拟器逐秒输入水位和盖子状态，在终端打印状态切换和执行器命令。模拟时间可以直接跳到下一秒，无需真实等待。

## 目录

| 路径 | 用途 |
| --- | --- |
| `src/washer.mjs` | 洗涤状态机，接收输入快照并返回执行器命令 |
| `src/config.mjs` | 洗涤、漂洗、进排水超时的初始参数 |
| `sim/demo.mjs` | 模拟水位变化并演示一次完整洗涤 |
| `test/washer.test.mjs` | 验证完整流程、停机、开盖、缺水和超时 |

## 控制流程

```text
待机 → 进水 → 洗涤 → 排水 → 漂洗进水 → 漂洗 → 最终排水 → 完成
```

进水达到目标水位后才运行洗涤动作，排水达到低水位后才结束当前排水阶段。运行中按停止、开盖、洗涤或漂洗时跌到低水位，或进排水超时，都会关闭所有输出。故障或停止后，需要合盖并复位，再重新按启动。若复位时桶内还有水，下次启动会先排到低水位。

## 接入硬件

控制器的 `update(nowMs, inputs)` 接收单调递增的毫秒时间和一份输入快照。

- `lidClosed` 是盖子是否关闭。
- `waterLevel` 为 `empty`（低水位）、`between`（介于低水位与目标水位之间）、`target`（达到目标水位）或 `invalid`（读数无效）。
- `start`、`stop`、`reset` 表示当前按钮是否按下。启动使用按下沿。
- 返回的 `outputs` 包含 `fill`、`agitate`、`drain` 三个布尔命令，以及当前状态和停机原因。调用方应在每次更新后应用全部输出。

选好芯片后，按这个接口移植控制逻辑。板端负责采集和消抖、处理计时器回绕，并将命令映射到实际执行器。机械结构决定 `agitate` 的具体动作，比如电机转速、换向和停顿。当前时长用于流程验证，实际水位、时长和故障保护需要在硬件上重新验证。本版流程到最终排水结束。
